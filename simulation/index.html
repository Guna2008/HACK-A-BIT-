How the system works

  1. The first LM393 module becomes active when the simulated temperature reaches 40°C.
  2. The AND gate activates only when both the flame sensor and the 40°C sensor are active.
  3. The OR gate activates the alarm if the AND gate output is active or the second LM393 module reaches 60°C.
  4. The buzzer is represented by the alarm status display.
